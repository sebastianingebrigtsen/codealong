# CodeAlong

**Coding tutorials that wait for you.**

Start typing in VS Code and the coding tutorial in Chrome pauses. Stop typing, and it rewinds two
seconds and continues.

![CodeAlong pauses the tutorial while you code](https://raw.githubusercontent.com/sebastianingebrigtsen/codealong/main/assets/store/chrome-screenshot-1280x800.png)

## Install both parts

- [CodeAlong for Chrome](https://chromewebstore.google.com/detail/codealong/jhfmljdjpeaclncddhhifegcknjgfjij) – controls the video
- [CodeAlong for VS Code](https://marketplace.visualstudio.com/items?itemName=SebastianIngebrigtsen.codealong) – notices that you are coding

Then open a tutorial, click the CodeAlong icon in Chrome and choose **Follow this tab**.
