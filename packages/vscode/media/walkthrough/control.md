## Settings and shortcuts

**Timing lives in Chrome.** Click the CodeAlong icon → **Settings**:

| Setting                           | Default |
| --------------------------------- | ------- |
| Continue after I stop typing      | on, 5 s |
| Continue when I save              | on      |
| Rewind before continuing          | on, 2 s |
| Continue when I return to the tab | off     |
| Show status on the video          | on      |

Changes apply to VS Code instantly.

| Action                     | Windows / Linux | macOS |
| -------------------------- | --------------- | ----- |
| Pause or play the tutorial | `Ctrl+Alt+P`    | `⌃⌥P` |
| I'm done, continue now     | `Ctrl+Alt+D`    | `⌃⌥D` |

- **Turn off for a while:** click **CodeAlong** in the status bar, or use the switch in the Chrome popup.
- **Change shortcuts:** Keyboard Shortcuts → search for "CodeAlong".
