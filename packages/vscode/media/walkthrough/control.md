## Shortcuts and settings

| Action                     | Windows / Linux | macOS |
| -------------------------- | --------------- | ----- |
| Pause or play the tutorial | `Ctrl+Alt+P`    | `⌃⌥P` |
| I'm done, continue now     | `Ctrl+Alt+D`    | `⌃⌥D` |

- **Turn off for a while:** click **CodeAlong** in the status bar → _Turn Off CodeAlong_, or use the switch in the Chrome popup.
- **Change timing:** Settings → search for "CodeAlong" (idle delay, rewind, resume on save, …).
- **Change shortcuts:** Keyboard Shortcuts → search for "CodeAlong".
