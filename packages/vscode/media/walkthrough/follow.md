## Choose the tutorial

1. Open the tutorial in Chrome.
2. Click the **CodeAlong** icon in the toolbar. Pin it via the puzzle-piece menu so it's always visible.
3. Click **Follow this tab**.

Only that tab is ever controlled, even with other videos open. The toolbar icon shows **ON** when Chrome and VS Code are connected.

On sites other than YouTube, Vimeo and Laracasts, Chrome asks once for permission to access that site.
