# Code of Conduct

CodeAlong follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, kind and constructive. Harassment, insults and personal attacks are not
tolerated in issues, pull requests, discussions or any other project space.

## Reporting

If you experience or witness unacceptable behaviour, contact the maintainer
([@sebastianingebrigtsen](https://github.com/sebastianingebrigtsen)) privately through
[a private security advisory](https://github.com/sebastianingebrigtsen/codealong/security/advisories/new)
(it's the private channel GitHub offers for this repository), and mark it as a Code of Conduct report.
Reports are handled confidentially. The maintainer may remove content and block participants who
break this code, following the Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
